# UniMate

**Your University. Your People.**

UniMate is a student-only social platform concept for the International Information Technology University (IITU) community in Almaty, Kazakhstan.

## Current implementation

The first frontend foundation includes:
- Responsive React + TypeScript application
- UniMate burgundy visual identity
- Student community dashboard
- Campus feed with interactive like buttons
- Suggested students and campus places panels
- Responsive desktop, tablet, and mobile layouts

## Planned modules

- IITU email registration and verification
- Student profiles and interests
- Discover students and friend requests
- Feed, posts, likes, and comments
- Campus places map
- Private messaging and notifications
- Privacy controls and moderation

## Technology

- React 18
- TypeScript
- Vite
- Lucide React icons
- Supabase / PostgreSQL (planned backend)
- Leaflet + OpenStreetMap (planned map integration)

## Brand

## Run locally

```bash
npm install

```
